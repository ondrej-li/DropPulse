Características y funcionamiento de DropPulse

Seguimiento automatizado de disponibilidad

DropPulse supervisa en segundo plano las páginas públicas de entradas para detectar asientos o entradas liberadas.

Alertas inmediatas por correo electrónico

En cuanto se liberan entradas, DropPulse envía una alerta a su correo con un enlace directo de compra.

Monitorización ética sin evasión

No resolvemos CAPTCHA de forma automatizada. Ante desafíos antibot, el control se pausa para verificación manual.

Privacidad y datos mínimos

El inicio de sesión sirve únicamente para gestionar alertas. Sin rastreadores publicitarios ni venta de datos.

Propósito de la aplicación y cumplimiento de Google API

La aplicación DropPulse se dedica exclusivamente a monitorizar la disponibilidad de entradas de eventos y enviar avisos. El inicio de sesión con Google requiere permisos mínimos (openid, email, profile).

El uso de la información obtenida a través de las API de Google cumple estrictamente con la Google API Services User Data Policy y los requisitos de Limited Use.

Prohibición de AI NCII: De conformidad con los Términos del servicio de las API de Google, DropPulse no utiliza las API de Google ni sistemas de IA para crear o distribuir imágenes íntimas sin consentimiento (AI NCII) ni contenido perjudicial.

Por ahora el acceso es por invitation. Solo las cuentas invitadas pueden iniciar sesión; el registro está cerrado.
