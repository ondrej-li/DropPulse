DropPulse の主な機能と仕組み

空き状況の自動モニタリング

DropPulse は公開されているチケットページをバックグラウンドで巡回し、座席の開放を検知します。

即時メール通知

チケットが利用可能になった瞬間に、確認済みメールアドレスへ直接リンク付きのアラートを送信します。

セキュリティ保護を回避しない倫理的な設計

CAPTCHA の自動突破などは行いません。ボット判定画面が出た場合は一時停止し、手動確認を促します。

プライバシー重視と最小限のデータ取得

ログインは監視項目の管理と通知送信用にのみ使用されます。広告トラッカーやデータ販売はありません。

アプリケーションの目的と Google API 利用規約の遵守

DropPulse は、イベントチケットの空き状況の監視およびメール通知配信を目的としたアプリケーションです。Google ログインは、最小限のスコープ（openid、email、profile）によるユーザー認証にのみ使用されます。

Google API から取得した情報の使用は、限定使用（Limited Use）要件を含む Google API Services User Data Policy に完全に準拠しています。

AI NCII（同意のない親密な画像）の禁止: Google API 利用規約に従い、DropPulse は Google API や AI 技術を使用して、同意のない親密な画像（AI NCII）や有害なコンテンツを生成、処理、配布することは一切ありません。

現在、アクセスは招待制です。 招待されたアカウントのみサインインできます。新規登録は停止しています。
